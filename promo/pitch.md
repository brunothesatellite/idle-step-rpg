# Pitch — La Marche des Âmes

## Titre pour Reddit

**RPG de marche sous Android où vos pas sont la seule ressource (gratuit, sans pub ni achats, sans IA, open source)**

## Texte principal (Reddit / Facebook)

Salut,

Je suis quelqu'un qui marche (un peu) et surtout qui court (beaucoup). Ancien développeur, je continue à bricoler diverses applications et jeux sur mon temps libre. Depuis un moment je cherchais un truc mélant course à pied / marche et jeu (genre Stepcraft pour les connaisseurs mais en moins usine à gaz). Genre un jeu de rôle basé sur les pas que je fais chaque jour. J'ai fini par coder **La Marche des Âmes** (DungeonStep) : un RPG pixel art un peu (carrément) old-school où vous suivez un héro (Kaelen) qui combat dans un donjon infini. Sauf que sa seule ressource, ce sont **vos pas** !

Le principe est simple : **pas de pas, pas de progression**. Pas de pub, d'achat, de partage Instagram ou je ne sais quoi pour récupérer des pas. Le seul moyen ce sont vos vrais pas, dans votre vraie vie, même s'il fait moche dehors. Kaelen avance quand vous marchez, court quand vous courez, et s'arrête quand vous vous arrêtez. Les pas remplissent une réserve ; cette réserve sert à marcher dans le donjon, à lancer les combats, à ouvrir des coffres, à farmer. Quand la réserve est vide, Kaelen finit par s'arrêter.

C'est un jeu en partie « idle » dans le sens où vous n'avez pas besoin de rester le nez dessus : vous faites votre sortie, vous revenez, Kaelen a avancé (il consomme hors ligne un fraction des pas que vous avez effectué pour avancer et combattre seul), vous équipez, vous améliorez votre équipement / personnage, vous repartez. Mais ce n'est pas un jeu qui tourne tout seul : sans vos pas, il ne se passe rien. Et parfois il vaut mieux passer du temps à améliorer votre équipement pour progresser plus vite.

Ce que je voulais, et ce que je veux garder :

- **Pas de publicité.** (bien que Franck Leboeuf qui veut vendre votre voiture m'aurait fait marrer dans le jeu)
- **Pas d'achats in-app.** Tout est gratuit, et tout le restera, je suis un (presque) vieil imbécile qui a connu l'aube d'internet et qui croit encore au partage sans rémunération.
- **Pas de contenu généré par IA.** Les textes sont écrits à la main, j'écris tout de même une partie de mon code et de la doc en m'aidant d'IA (VS Code / Github Copilot / Opencode) - comme tout développeur en 2026, non ? Les visuels sont du pixel art, pas des images générées.
- **Pas de collecte de données.** L'appli n'a pas de serveur à elle, pas de compte chez moi, pas d'analytics. Les pas sont lus localement sur votre téléphone (Santé Connect), ou via votre source Garmin (clé API Garmin personnelle à fournir à l'application) si vous choisissez cette option. Rien n'est revendu.
- **Le code est entièrement disponible** sur GitHub. Vous pouvez lire, compiler, modifier, auditer (et corriger mes bugs !), forker.

Au départ, c'était un projet perso pour moi pour me marrer et quelques amis coureurs. Ça a bien grandi, et je suis content de pouvoir le partager plus largement. Je ne gagne rien dessus (je ne suis pas prêt de rembourser les 25€ nécessaire à l'ouverture du compte Google Play Store); si ça vous amuse, c'est déjà beaucoup.

Deux façons de l'installer :

- **Play Store** : https://play.google.com/store/apps/details?id=com.brunothesatellite.idlesteprpg
- **GitHub** (APK à installer manuellement, en sideloading ; Android vous affichera un avertissement, c'est normal) : https://github.com/brunothesatellite/idle-step-rpg/releases/latest

La version GitHub est mise à jour **plus souvent** que celle du Play Store (la validation d'une application sur le Play Store étant plus longue, je publie dessus bien moins régulièrement que sur Github).

Le projet et le code : https://github.com/brunothesatellite/idle-step-rpg

Une vidéo de présentation : https://www.youtube.com/shorts/E51AA6Y6Rg8

L'appli demande **Android 14 ou plus**. Si vous testez, n'hésitez pas à me dire ce qui vous plaît ou ce qui vous bloque. Je suis surtout curieux de savoir si le rythme « je marche → mon perso avance » tient sur la durée.

Bonnes marches, bonnes courses !

## Version courte (groupes Facebook / posts rapides)

Salut,

Je vous partage un projet perso : **La Marche des Âmes**, un RPG pixel art où vos pas sont la seule ressource. Pas de pas, pas de progression ; pour faire avancer Kaelen (le héro), il faut marcher ou courir. C'est gratuit, **sans pub, sans achat in-app, sans contenu généré par IA et sans collecte de données**. Le code est open source.

Ca fonctionne sous Android 14+. Vous pouvez l'installer depuis le Play Store (https://play.google.com/store/apps/details?id=com.brunothesatellite.idlesteprpg) ou depuis GitHub en sideloading (https://github.com/brunothesatellite/idle-step-rpg/releases/latest). La version GitHub est mise à jour plus souvent. Le projet : https://github.com/brunothesatellite/idle-step-rpg

Vidéo de présentation : https://www.youtube.com/shorts/E51AA6Y6Rg8

Si vous testez, je suis preneur de vos retours.
