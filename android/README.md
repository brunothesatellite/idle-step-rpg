## Français

Le README racine est la source unique de documentation : [`../README.md`](../README.md).

Il couvre l’installation, les sources de pas (Garmin et Santé Connect), les mises à jour, les tests, l’architecture, la persistance et la structure du dépôt, en français puis en anglais.

Points spécifiques au module Android :

- **Compiler** : `./gradlew :app:assembleGithubDebug` (debug) ou `:app:assembleGithubRelease` (APK) et `:app:bundlePlayRelease` (AAB Play).
- **Tests** : `./gradlew :app:testDebugUnitTest` et `./gradlew :app:lintDebug`.
- **Prérequis** : JDK 21, Android SDK 36, build-tools 36.0.0.
- **Manuel** : `../manuel/index.html` (FR) et `../manuel/en/index.html` (EN), générés par la tâche Gradle `generateManual`.
